## ArchEngine CAD Changes

### Wall Layer System

**Files Modified:**
- `ArchEngine_CAD/core/document.py`
- `ArchEngine_CAD/views/plan_view.py`

#### New Data Classes (document.py)

```python
@dataclass
class WallLayer:
    name: str
    material: str
    thickness: float  # mm
    function: str
    color: Tuple[float, float, float, float]  # RGBA 0-1
    r_value: float = 0.0

@dataclass
class WallType:
    id: str
    name: str
    layers: List[WallLayer]
    total_thickness: float = 0.0
```

#### New Methods (document.py)
- `get_wall_type(type_id: str) -> Optional[WallType]` - Retrieve wall type by ID
- `get_walls_at_point(x, z, tolerance) -> List[Tuple[int, str]]` - Find walls at a point

### Editable Wall Layers (plan_view.py)

**New Class: `WallLayerItem`**
- Each wall layer is now a separate selectable/editable graphics item
- Individual layers can be selected independently
- Orange grips at start/end allow extending/retracting each layer
- Supports layer-specific extension adjustments

**Key Features:**
- `start_extension` / `end_extension` - Per-layer extension control
- Grips appear on hover or selection
- Layer colors from wall type definition

### Corner Connection System

Implemented butt joint corners (realistic construction):
- Primary wall (lower index) continues with square cut
- Secondary wall butts into primary wall's face
- `_get_butt_joint_points()` method calculates intersection

## Usage

### CAD - View Wall Layers
1. Run `python main.py` in ArchEngine_CAD
2. Walls display with colored layers from wall type definition
3. Click a layer to select it
4. Drag orange grips to extend/retract individual layers

### Unreal - Enable Dimensions
1. Rebuild Unreal project
2. Select ArchBuildingActor in level
3. In Details panel, find **ArchEngine|Dimensions**
4. Check **Show Dimensions**
5. Toggle individual dimension types as needed

### Unreal - Export Construction Drawing
1. In Details panel, find **ArchEngine|Drawing**
2. Check **Enable Drawing Camera**
3. Select **Drawing View** (Plan, FrontElevation, etc.)
4. Adjust **Ortho Width** for zoom level
5. Call **Export Drawing To File** with path (e.g., "C:/Temp/FloorPlan.png")
